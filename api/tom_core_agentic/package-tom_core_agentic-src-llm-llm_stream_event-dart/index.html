class LlmFailure

final class LlmFailure

Typed failure envelope.

[classCode] is a stable snake_case discriminator (e.g. rate_limit, overloaded, billing, timeout, auth, auth_permanent, model_not_found, context_overflow, format, network, cancelled_by_consumer, unknown).

A provider emits only the classes it can settle by itself, which is two of them: format when the backend's own stream was malformed — the provider observed that directly, and flattening it to unknown would throw away the one thing it does know — and unknown for every failure whose meaning would take backend-specific interpretation to recover. Mapping those onto the rest of the taxonomy is the caller's job. So a consumer switching on [classCode] must handle both format and unknown from this layer; consumers that only need to log or surface the failure use [message] instead.

Constructors

Properties

final String classCode

Stable snake_case discriminator.

final String message

Human-readable diagnostic. Not for end-user display; for logger / trail entries.

final Object? cause

Optional underlying error. Carried for debugging only — consumers should not pattern-match on its runtime type.

class LlmStreamEvent

abstract sealed class LlmStreamEvent

Events emitted on a Stream<LlmStreamEvent> from [LlmProvider.completeStream].

Lifecycle: - Exactly one [LlmStreamStarted] is emitted first. - Zero or more [LlmStreamChunk] events follow, in order. - Zero or more [LlmStreamToolCallProposed] events may be interleaved with chunks; the provider pauses the stream after a tool-call until the caller resolves it. - The stream terminates with exactly one of [LlmStreamCompleted] or [LlmStreamFailed].

class LlmStreamStarted

final class LlmStreamStarted extends LlmStreamEvent

First event on every stream. Carries the call id assigned by the caller so consumers can correlate subsequent chunks with the originating call.

Constructors

const LlmStreamStarted.new({required String callId, required String providerId, required String modelId})

Properties

final String callId

Opaque identifier for this call. Matches the callId field of [LlmStreamCompleted] / [LlmStreamFailed].

final String providerId

Provider that was selected for this call. Equals the emitting provider's id, and the providerId of the [LlmCallReport] the stream terminates with.

final String modelId

Model id within the provider — the resolved one, after any LlmOptions.model override, and equal to the terminating report's modelId. Hardcoding the pair here (which a const constructor forces) is what makes a stream announce one route and complete on another.

class LlmStreamToolCallProposed

final class LlmStreamToolCallProposed extends LlmStreamEvent

The provider proposed a tool call. The stream is paused while the caller resolves the call; resumption happens when the caller posts the tool result back.

arguments is the JSON-shaped argument object the provider emitted, validated against the tool's parametersSchema. Validation failures surface as a [LlmStreamFailed] event.

Constructors

Properties

final String toolCallId

Provider-side tool-call id. Used by the caller to post the resolution back; not interpreted here.

final String toolName

The tool's canonical name (matches a [ToolDescriptor.name] in the call's [ToolCatalogue]).

final Map<String, Object?> arguments

Argument object, JSON-shaped.
