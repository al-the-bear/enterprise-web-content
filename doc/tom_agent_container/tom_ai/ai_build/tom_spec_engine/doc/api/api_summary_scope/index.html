TomSpecs Engine API Reference: Scope Module

The scope model: the SpecController port a host supplies, the named scopes a script runs under, and the registry that assembles them.

For task-oriented guidance see scripting.md. For what each scope is, see llm_and_d4rt_tools.md §4–§7.
