Appendix A5 · Glossary & cross-reference

Appendix A5 of the Tom Core advanced-sample user guide — see the guide index.

This closing appendix is the guide's lookup table. It gathers in one place (1) the vocabulary the spine builds up section by section — so a term you meet mid-guide has a single definition you can jump back to — and (2) two cross-reference maps: from each package README to the guide section that explains it, and from each planning document that drove the sample to the sections that carry its content. Nothing here is new; every entry points at the spine part or appendix that establishes it. If you read the guide front to back you will have met all of it — this appendix just lets you re-find it.

Glossary

Alphabetical. The Established in column is the canonical place the term is defined; an anchor beside it names the declaration that enforces or uses the term — a type, a member, or a function — together with its file, because a name survives the edit that moves a line.

TermMeaningEstablished in
basePath A field's identity string, <scopePath>.<formId>.<tomId> . It is both the authorization grade key (bare path) and the prefix for its text keys (path + suffix). One name configures display and access. A2 ; tom_form.dart — TomForm.prepareForSelfObservation / the TomField constructor
bearer / JWT pair The access + refresh JSON Web Token pair the auth server mints at login (2 h access lifetime). The client presents the access token as an HTTP bearer on every app-server request; the app server validates it offline against the shared signing key. 06 , A3 ; AuthTokenService._issueFor in auth_endpoints.dart
bundle (resource bundle) A server-delivered map of basePath.suffix → text ( ResourceBundleDto ), installed via TomTextResourceProvider.setAppResourceProvider . A small pre-login bundle (public loginResources ) installs first; the full bundle replaces it after sign-in. 08 ; AppSession._installResources in app_session.dart , AdvancedAppApiService.resources in app_endpoints.dart
column grade (C-4) A per-column authorization state, named by @TomDbColumn(authKey:) . The framework resolves it from the process-global TomAuthorization unless a per-row resolver is registered for the key on TomRowColumnAuthorization ; the app server registers one for todo.item.attachment , composing the caller's role on the row with that role's grant. Below full the file endpoint answers 403 ( column_authorization.{read,write}.field_forbidden ) — the row is not in question, the column is. 13 , 10 ; column_grade_resolver.dart
closed-safe default The rule that an unknown or absent grade resolves to TomAuthState.none (hidden), enforced independently at three points on the client read path: an ungranted <type>:<id> resource key resolves to none (the AppResourceRoleAdapter ), a roleName with no matching ProjectRole yields none , and a field with no grade in projectRoleFieldGrades[role] narrows to none . The server WRITE-path resolver defaults the same. Failure of any point hides a field rather than exposing it. A1 ; app_resource_role_adapter.dart , FieldGradeResolver.resolveItemFieldStates in field_grade_resolver.dart
cross-tier integration runner run_cross_tier_integration.sh — the scripted end-to-end harness that boots both MariaDB databases and both servers, runs every live suite in the package ( cross_tier_integration_test.dart , auth_client_integration_test.dart , file_transfer_integration_test.dart , app_api_client_integration_test.dart , admin_api_client_integration_test.dart ), and treats unreachable services as failure (not skip). 12
datasource (main binding) A per-logical-DB connection configured in YAML. The app server binds the framework's main datasource to auth_db so it can read the shared grant table; cross-DB references are logical (no cross-DB foreign keys). 05 ; GrantRepository in field_grade_resolver.dart
field grade A field's per-principal authorization state — one TomAuthState value. On the app read it is computed on the client , by narrowing the item's registry-resolved resource ceiling with the shared projectRoleFieldGrades[role] row. Server-side FieldGradeResolver folds the same grade from the role's grant rows to enforce the write path. 07 , A1 ; _ItemDetailScreenState._resolveForm in item_detail_screen.dart , FieldGradeResolver.resolveItemFieldStates in field_grade_resolver.dart
file slot The addressable <entity>/<id>/<column> triple the framework file endpoint serves ( /files/{entity}/{id}/{column} ), published at boot by TomFileSlots.register(repository) from the entity's own annotations. Only columns declaring exposed: true get one; an unexposed column resolves to nothing and answers 404 , for every caller equally — exposure decides which column a slot names , never who may have it. 13 , 10 ; app_server_start.dart
formId A form's identifier and the middle segment of every field basePath . For an unscoped form (e.g. LoginForm , formId: 'login' ) the formId is the base path root → login.username . A2
four-state (TomAuthState) The four-value enum declared most-to-least restrictive: none < disabled < read < full . It maps a field to a control by resolved state alone — none collapses (hidden), disabled greys, read shows read-only, full makes editable. A1
graded DTO (GradedFieldDto) The per-cell grade of the admin grant matrix GrantMatrixDto ( GrantMatrixDto.gradesFor(role) ): a resourceKey + its access ( TomAuthState.name token). Served by the auth server's /admin/grants path and rendered in the admin console's grant editor; its closed-safe none default applies for unknown grades. It no longer travels on any app read . 04 ; grant_matrix_dto.dart
grant matrix / grant The tom_resource_grant rows mapping a role to its per-field grades, folded into a TomGradedAccessControlInformation via fromGrants . The single source of truth for field grades; stored in auth_db , read cross-DB by the app server. 07 ; FieldGradeResolver.gradesForRole in field_grade_resolver.dart
green gate The completion bar: dart analyze clean and every test suite green (run serially) and the cross-tier runner exits 0 . All three together — not any one alone. 12
per-field grade stamp How the app client applies field authorization: at login it installs the principal's resourceRoles as the global AppResourceRoleAdapter ; the item detail screen then grades each gradable field synchronously — field.authorizer = TomAuthorizer.fixed(resourceState.narrow(projectRoleFieldGrades[role][basePath] ?? none)) where resourceState = TomAuthorization.resolveAuth(ResourceRoleKeys.item(id)) (layer 4). There is no per-field installed adapter; a missing role or unsent grade is closed-safe ( none ). 07 , A1 ; _ItemDetailScreenState._resolveForm in item_detail_screen.dart , app_session.dart , app_resource_role_adapter.dart
principal (zone principal) The authenticated identity ( TomPrincipal ) for a request. The server reads it from the request zone, getFromCurrentZone<TomPrincipal>() — never the client-side TomBearerAuthentication singleton, which is not request-scoped. A3 ; AdvancedAppApiService._principalId in app_endpoints.dart , AdvancedAuthApiService.me in auth_endpoints.dart
reflection seed The one reflection_seed.dart per package whose main() touch-imports the reflected types; the generated reflection_seed.reflection.dart is the build output. Regenerated only on signature changes, via the package's reflection_generation.sh . 02 , 03
resource / text resource An externalized UI string keyed by basePath + suffix ( .label / .hint / .error.<code> ). No widget carries a hard-coded label/hint/error; each resolves from the installed bundle. 08 ; TomField.resolvedLabel in tom_form.dart
resourceRoles (AppResourceRoleAdapter) The app client's read path for authorization: GET /resource-roles returns the principal's flat resourceKey → roleName map ( AppApiClient.resourceRoles ), folded server-side from ownership + share grants expanded down each containment subtree. Fetched once at login and installed as the global TomAuthorization adapter via AppResourceRoleAdapter (gating only <type>:<id> keys; dotted paths stay permissive). The item screen resolves the item's resource ceiling through the registry and narrows it by projectRoleFieldGrades[role] to grade fields locally. 07 , A3 ; app_resource_role_adapter.dart , _ItemDetailScreenState._resolveForm in item_detail_screen.dart
role (ProjectRole) The ownership-or-share access level a principal has on a resource (owner / editor / viewer / commenter). Resolved by ResourceRoleResolver.resolveRole — the framework TomDelegationResolver folds the C-5 ownership grants and C-6 share -mode delegations into a flat effective-role map, then the resolver keeps the strongest over the item→list→project→workspace ancestry; null means no access (→ 404). 07
scope / scopePath The namespace pushed at the call site ( TomScope.withScope('todo', TodoItemForm.new) ) so a scoped form's field paths equal the server's grade keys. Constructing a scoped form unscoped silently breaks every grade/text lookup (renders empty, no throw). A2 ; _ItemDetailScreenState._resolveForm in item_detail_screen.dart
[srv] sentinel A test technique: install a bundle whose every value carries a [srv] suffix and assert the suffixed strings render. A hard-coded label would not carry the suffix and so fails the test — proving texts are server-delivered. 12
tomId A field's local id within its form — the leaf segment of basePath . Independent of the reflected member name used by bind / save (the deliberate estimate ↔ estimateHours divergence proves the decoupling). A2 ; TodoItemForm.estimateHours in todo_item_form.dart
