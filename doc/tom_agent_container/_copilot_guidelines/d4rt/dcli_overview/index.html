DCli Overview

> IMPORTANT: Use DCli for ALL file and directory manipulation in Tom CLI tools. Do not use dart:io directly for file operations — DCli provides cleaner, safer, cross-platform APIs with better error handling.

Overview of using the DCli library for shell-like operations in Dart projects within the Tom workspace.

What is DCli?

DCli is a Dart library that provides shell-scripting capabilities. It wraps common Unix operations (file manipulation, process execution, user input) in a Dart-native API. The same code can run:

  • Interpreted: dart run script.dart or via d4rt/tom
  • Compiled: dart compile exe script.dart for native binaries

When to Use DCli

Use DCli instead of direct dart:io calls when:

Use CaseWithout DCliWith DCli
Execute command Process.run('ls', ['-la']) 'ls -la'.run
Check file exists File(path).existsSync() exists(path)
Copy fileFile(from).copySync(to)copy(from, to)
Create directory Directory(path).createSync(recursive: true) createDir(path, recursive: true)
Get current dirDirectory.current.pathpwd
Get home dirPlatform.environment['HOME']HOME

Benefits: - Cleaner, more readable code - Consistent error handling - Cross-platform support (Unix/Windows) - Built-in color output and progress tracking

Core Functionality Categories

1. Process Execution

// Simple execution
'ls -la'.run;

// Capture output
var files = 'ls'.toList();
var version = 'dart --version'.firstLine;

// With progress tracking
start('long_command', progress: Progress((line) => print(line)));

2. File Operations

// Copy, move, delete
copy('source.txt', 'dest.txt');
move('old.txt', 'new.txt');
delete('unwanted.txt');

// Read content
cat('file.txt');
var lines = read('file.txt').toList();

3. Directory Operations

// Create and check
createDir('path/to/dir', recursive: true);
if (exists('path') && isDirectory('path')) { ... }

// Find files
find('*.dart', recursive: true)
  .forEach((file) => print(file.pathTo));

4. User Input

// Text input with validation
var name = ask('Enter name:', validator: Ask.alpha);

// Confirmation
if (confirm('Continue?')) { ... }

// Selection menu
var choice = menu('Select option:', options: ['A', 'B', 'C']);

5. Path Operations

// Construct paths
var full = truepath('dir', 'subdir', 'file.txt');
var parent = dirname(full);
var name = basename(full);

Best Practices

1. Prefer explicit paths over cd / push / pop 2. Use truepath() to ensure absolute, normalized paths 3. Handle exceptions - DCli throws typed exceptions (CopyException, DeleteException, etc.) 4. Use nothrow: true when non-zero exit codes are expected 5. Prefer .toList() over .run when you need output 6. Use Progress for long-running operations to track status

Critical API Behaviors (Gotchas)

These behaviors differ from shell expectations and can cause issues if not understood:

1. copyTree/moveTree Destination MUST Exist

// WRONG - throws: "The [to] path /dest must already exist"
copyTree('/src', '/dest');

// CORRECT - create destination first
createDir('/dest');
copyTree('/src', '/dest');

2. No Shell Variable Expansion

DCli does NOT expand shell variables like $HOME in command strings:

// WRONG - returns literal "$HOME" not the actual path
'echo $HOME'.firstLine;  // Returns: "$HOME"

// CORRECT - use Dart interpolation with env[]
'echo ${env['HOME']}'.firstLine;  // Returns: "/home/user"

// BETTER - access env directly without shelling out
final home = env['HOME'];  // Returns: "/home/user"

3. No Pipe Parsing

DCli does NOT parse shell pipes. Use Dart filtering instead:

// WRONG - tries to execute "cat file.txt | grep pattern"
// which fails because | is passed as an argument
'cat file.txt | grep pattern'.toList();

// CORRECT - use Dart filtering
final lines = read('file.txt').toList();
final filtered = lines.where((l) => l.contains('pattern'));

4. isOnPATH() vs which().found

isOnPATH() checks if a directory path is in PATH, NOT if a command exists: 

// WRONG - isOnPATH checks if "/usr/bin/bash" directory is in PATH
isOnPATH('bash');  // May return false even if bash exists

// CORRECT - use which() to find commands
if (which('bash').found) {
  print('bash found at: ${which('bash').path}');
}

5. Permission Functions Throw on Non-Existent Files

// WRONG - throws RunException for non-existent file
isReadable('/nonexistent');

// CORRECT - check existence first
if (exists(path) && isReadable(path)) { ... }

6. AskValidator Throws on Invalid Input

Validators throw AskValidatorException on invalid input, they don't return bool:

// In test code, use throwsA() matcher
expect(
  () => Ask.integer.validate('not a number'),
  throwsA(isA<AskValidatorException>()),
);

// Valid input returns the (possibly transformed) string
expect(Ask.integer.validate('42'), equals('42'));

7. move() Throws CopyException on Failure

When move() fails with cross-device moves (uses copy+delete internally):

try {
  move('/source', '/nonexistent_parent/dest');
} on CopyException catch (e) {
  // NOT MoveException!
  print('Move failed: ${e.message}');
}
